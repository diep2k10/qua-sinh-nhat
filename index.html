🎀 Tạo món quà sinh nhật

🔌 KẾT NỐI SUPABASE

Chưa kiểm tra kết nối. Nhập Project URL và Publishable/anon key rồi bấm nút phía trên.

Chỉ dùng publishable/anon key, tuyệt đối không đặt service_role key trong HTML.

🎂 BÁNH SINH NHẬT

Ba ảnh đầu tiên trong mục Ảnh kỷ niệm sẽ lần lượt xuất hiện trên ba tầng bánh. Số nến hiển thị tối đa 5 ngọn để bánh cân đối.

🎵 NHẠC NỀN

Dùng link HTTPS mở trực tiếp file âm thanh (MP3, OGG, WAV...). Link trang YouTube/Spotify thường không phát trực tiếp được.
